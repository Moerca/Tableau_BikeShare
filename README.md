# Tableau Bike Share London

This is a **Bike Share London** analysis project built with **Python** and visualized in **Tableau**. It leverages data from the **London Bike Share** system to provide insights on bike usage, station performance, and trends.

## Features

- Data analysis and processing using **Python**  
- Visualizations in **Tableau** for interactive exploration  
- Analyze key metrics such as station popularity, trip durations, and usage patterns  
- Provide insights on seasonal trends, peak hours, and bike availability  

## Tech Stack

- **Python** (for data processing)  
- **Tableau** (for data visualization)  
- Pandas (for data manipulation)  
- Matplotlib/Seaborn (for initial visualizations)
